# Resume profiles (presets)

Presets define **how** to frame a resume PDF for a target (role, stack, ATS).
Canonical facts stay in `src/content/{pt,en,es}.ts`. Profiles only select, order, and emphasize.

## Modes

| Mode | Use |
|------|-----|
| `brand` | Site download button — visual layout, full storytelling |
| `recruiter` | Platform uploads / headhunters — denser, keyword-led |

## Layout

```text
src/resume/
  types.ts              # ResumeProfile contract
  index.ts              # public API
  skill-aliases.ts      # PT/ES skill labels → canonical EN
  profiles/
    brand.ts
    default.ts
    backend-node.ts
    backend-go.ts
    backend-python.ts
    fullstack-node.ts
    fullstack-python.ts
    architect.ts
    infra-architect.ts
    tech-leader.ts
    frontend-react.ts
    sre-devops.ts
    index.ts            # registry + get/require
```

## Fields that matter

- `targetTitle` — title line on the PDF (may differ from the site hero)
- `emphasizeSkills` — priority order; use canonical EN labels (`Microservices`, …). PT/ES resolve via `skill-aliases.ts`
- `experienceFocus` — featured companies (exact match on `company`)
- `maxExperienceItems` — max roles listed
- `extraKeywords` — domain terms for ATS
- `summaryFocus` — tags for the future summary assembler

## Adding a preset

1. Create `src/resume/profiles/<id>.ts` exporting a `ResumeProfile`
2. Register it in `src/resume/profiles/index.ts` (`resumeProfiles`)
3. Use company names and skill tokens that match `src/content/` (EN canonical for localized skills)

For a one-off job: add `profiles/acme-credit.ts` (or similar), generate the PDF, remove later if not reusable.

**Easter egg:** on the live site (v6), click the Mandril logo **7 times** within ~3s to open a menu of every preset PDF for the current locale.

## Generate a PDF (CLI)

`npm run resume` rebuilds the site first so content edits show up in the PDF.
Use `--no-build` only when `dist/` is already fresh.

```sh
npm run resume -- --profile backend-node --locale en
# → out/resume/Jonatas-Pedraza-backend-node-en.pdf

npm run resume -- --profile brand --locale pt --no-build
npm run resume:list
```

Recruiter HTML source: `/resume/recruiter/<profile>/<locale>/`  
Brand HTML source: `/resume/<locale>/` (unchanged site download pipeline)

Note: the dense “10+ anos de experiência …” line lives in `about.recruiter` (recruiter presets). The `brand` PDF uses `about.body` (storytelling), so that phrase will not appear there.
